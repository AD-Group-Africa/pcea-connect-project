# PCEA Connect – Frontend Documentation
**Version 1.0**

## Framework
- Next.js 15 (Webpack)
- TypeScript
- Tailwind CSS
- ShadCN UI

## Pages (26 routes)
/login, /register, /forgot-password, /reset-password, /dashboard, /feed, /livestream, /notifications, /media, /locator, /church, /members, /events, /giving, /ministries, /attendance, /pastoral-care, /bible, /analytics, /admin, /volunteer, /search, /membership-card, /sermons

## Design System
- Colors: PCEA Blue (#0B5E9C), Navy (#0B1622), Dark Gray (#111827)
- Typography: Plus Jakarta Sans (headings), Inter (body)
- Components: Cards (soft shadows), Dark Mode toggle
- Accessibility: 48px+ touch targets, ARIA labels

npm run build && npm start
