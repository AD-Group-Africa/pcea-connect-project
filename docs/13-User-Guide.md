# PCEA Connect – User Guide
**Version 1.0**

## Sign In
Enter email and password. Use Forgot password? if needed.

## Home
Greeting, verse of the day, upcoming events, quick actions.

## Giving
Select type, amount, M-Pesa number ? Submit ? confirm prompt.

## Events
View events, register, check in with ticket code.

## Bible
Select book/chapter, read, bookmark, highlight, share. Track streak.

## Ministries
View ministry hubs with feed, members, and projects.

## Prayer
Submit requests, pray for others.

## Profile
View membership card with QR code on Membership Card page.
